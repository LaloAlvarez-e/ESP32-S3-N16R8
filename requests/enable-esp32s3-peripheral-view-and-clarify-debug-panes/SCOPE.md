# Scope

## In Scope

- ESP-IDF extension debug-view configuration for this workspace.
- Supplying an ESP32-S3 SVD file for the Peripheral View.
- Documentation clarifying which panes work with the current `gdbtarget` adapter.

## Out of Scope

- Replacing the debug adapter with a different debugger stack.
- Upstream changes to the ESP-IDF extension or VS Code debug APIs.
