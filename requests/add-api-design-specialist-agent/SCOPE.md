# Scope

## In Scope

- Add one repository specialist agent for embedded API design.
- Define the agent responsibilities, constraints, and output format.
- Update existing repository delegation instructions so the new agent can be selected.
- Maintain the required request-tracking files for this request.

## Out of Scope

- Changing the MISRA review agent responsibilities.
- Running an actual API design task with the new specialist in this request.
- Changing the embedded coding rules beyond delegation behavior.
