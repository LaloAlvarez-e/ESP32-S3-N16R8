# Scope

## In Scope

- Add module-based folder architecture rules to the repository skills.
- Define the top-level common library layout for ESP32 repositories.
- Add the example nested project tree provided by the request.
- Define header aggregation and dependency direction rules.
- Create and maintain the required request-tracking artifacts.

## Out of Scope

- Creating the actual `common_utils/`, `common_os/`, `common_driver/`, or project folders.
- Generating build scripts or static library configuration files.
- Adding source code modules beyond the skill documentation itself.
