# Scope

## In Scope

- Create the requested top-level repository skeleton.
- Add concrete placeholder headers and source files that reflect the repository rules.
- Add local `test/` folders for each shared library and the sample project.
- Maintain the required request-tracking files for this request.

## Out of Scope

- Adding build-system files or static-library configuration.
- Integrating the sample project with real ESP-IDF configuration.
- Implementing full production behavior beyond scaffold-level placeholders.
