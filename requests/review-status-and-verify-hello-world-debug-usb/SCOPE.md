# Scope

## In Scope

- Summarize current repository progress from AGENTS.md and request trackers.
- Check whether the ESP32-S3 USB serial port is currently visible.
- Check whether the hello world OpenOCD debug path is currently usable.

## Out of Scope

- Changing firmware, toolchain, or driver configuration unless required for a minimal diagnostic.
- Flashing new firmware unless required to validate the current debug path.
