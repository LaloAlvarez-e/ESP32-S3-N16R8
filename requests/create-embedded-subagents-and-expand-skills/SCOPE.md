# Scope

## In Scope

- Create a user-invocable repository agent for embedded firmware tasks.
- Create focused repository subagents for ESP32 debugging, GoogleTest review, and Doxygen documentation.
- Expand the existing skills with concrete templates and review checklists.
- Update workspace guidance if the new subagents should be referenced directly.
- Maintain the request-tracking artifacts for this request.

## Out of Scope

- Adding source code, firmware modules, or tests for product features.
- Introducing build scripts, toolchain configuration, or CI workflows.
- Changing the core repository coding standard beyond clarifying workflow support.

## Delivered

- Main embedded repository subagent
- Specialized debugging, GoogleTest, and Doxygen subagents
- Skill templates and review checklists
- Updated workspace instructions to reference the new subagents
