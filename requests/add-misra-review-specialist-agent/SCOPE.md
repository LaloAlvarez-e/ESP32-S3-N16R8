# Scope

## In Scope

- Add one more repository specialist agent for MISRA-oriented review.
- Define the agent responsibilities, constraints, and review output format.
- Update existing repository delegation instructions so the new agent can be selected.
- Maintain the required request-tracking files for this request.

## Out of Scope

- Adding a separate API-design specialist agent.
- Changing the embedded coding rules themselves.
- Running an actual code review task with the new specialist in this request.
