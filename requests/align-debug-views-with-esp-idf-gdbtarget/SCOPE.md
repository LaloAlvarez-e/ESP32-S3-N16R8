# Scope

## In Scope

- Debug view behavior in the current ESP-IDF `gdbtarget` workflow.
- Workspace configuration changes that improve debug pane usability without replacing the adapter stack.
- Documentation of supported and unsupported debug-pane behavior.

## Out of Scope

- Upstream changes to the ESP-IDF extension, VS Code, or other marketplace extensions.
- Building a custom debug adapter.
- Replacing the repository's current ESP-IDF debug workflow unless that is explicitly requested.
