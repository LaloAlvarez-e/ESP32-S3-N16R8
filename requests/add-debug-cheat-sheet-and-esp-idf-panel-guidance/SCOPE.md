# Scope

## In Scope

- Repository documentation for ESP32-S3 GDB usage.
- Documentation of ESP-IDF VS Code views that can be used from this workspace.
- Clarifying which parts of the view layout can and cannot be persisted from repo files.

## Out of Scope

- Upstream ESP-IDF extension changes.
- Forcing VS Code to persist view visibility through unsupported workspace internals.
- Changing the existing debug adapter stack.
