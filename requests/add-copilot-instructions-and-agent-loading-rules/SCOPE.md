# Scope

## In Scope

- Create a workspace `copilot-instructions.md` file.
- Require reading `AGENTS.md` before substantial work.
- Require loading the relevant repository skills for embedded and ESP32 tasks.
- Require using the most appropriate repository subagent when one exists.
- Create and maintain the mandatory request-tracking files for this task.

## Out of Scope

- Creating the custom embedded subagent files themselves.
- Changing the embedded coding rules or ESP32 workflow skill content beyond what already exists.
